# Die With Zero Simulator

A phone and tablet game table for the Die With Zero board game, inspired by Bill Perkins' book *Die With Zero*. Up to 5 players. Every step is a button and LEP is calculated automatically; only "Dare Yourself" is done in real life.

**Play / install:** https://wkahjian93.github.io/die-with-zero-simulator/

- iPhone / iPad: open the link in Safari → Share → **Add to Home Screen**.
- Android: open the link in Chrome → ⋮ menu → **Install app** (or **Add to Home screen**).

It works offline after the first open. See [HOW TO USE.md](HOW%20TO%20USE.md) for the rules and how to run a game.

## For updates

- `index.html` is the game (single file).
- `node build.js` rebuilds the installable app into `docs/` (served by GitHub Pages).
- `node serve.js docs` tests the built app at http://localhost:5187.

Coaching in this game is based on the ideas in Bill Perkins' book Die With Zero, for learning and discussion. It is not personal financial advice.
